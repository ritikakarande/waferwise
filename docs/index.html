Can you beat the wafer model?

Each square is one chip (die) on a silicon wafer: grey dies passed testing, orange dies failed. The pattern of failures points to what went wrong in the fab. A small neural network runs right here in your browser and reads the pattern in a few milliseconds.

You are the gate

The model decides alone only when its confidence reaches a threshold. Below it, the wafer goes to a person. A higher threshold means fewer mistakes but more work for people. These figures come from the validation wafers, none of which were used to train the model.

The page runs the final model (FP32 ONNX, 0.4 MB) with ONNX Runtime Web, so nothing leaves your browser. The 261 wafers are a random draw from the validation split of WM-811K, 30 per class (21 for Near-full, the rarest). Dataset labels are not always right: an audit of this dataset found suspect labels.
